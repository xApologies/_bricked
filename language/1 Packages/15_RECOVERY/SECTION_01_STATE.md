# Section-01 State

**Closed design decisions**

- Genesis targets a Chirality Machine, not raw CPU instructions.
- Persistent fabric image is immutable during ordinary execution.
- Dynamic Geometrics/MMOs are overlays/realizations on the fabric.
- A physical-state codec maps logical state classes to device-specific storage states.
- Commodity storage is permitted as a backend but does not define semantic state by raw voltage.
- 2×2×2 chirality arrangement is primary; byte serialization is representation.
- Exact scientific mote adjacency remains a gate and is not fabricated.
- BRANE M5 and scientific 3+1+1 remain separate with explicit adapter.
