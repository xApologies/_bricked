# Genesis v1.0 Freeze Constitution

Genesis v1.0 is frozen at the semantic and machine-contract boundary. A v1.x implementation may optimize, add tooling, add libraries, or add compatible backends, but it may not silently change the meaning of a frozen operation, relax a verifier obligation, rewrite provenance/history semantics, conflate QFT and GR representations, assign BRANE realization coordinate Z from an external M5 module, or introduce a direct durable BLACKGLASS mutation channel.

Breaking changes belong to Genesis 2.0. The frozen release is a computational/software specification plus reference implementation. Physical chirality-native hardware remains a future backend target.
