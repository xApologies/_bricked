# BRANE re-lift after transformation

A transformed child is re-described to BRANE as:

`M^5 = (I, D, Chi, R, P)`

- **I**: canonical MMO identity, new live instance, representation identity;
- **D**: inherited dependencies plus transformation-plan dependency;
- **Chi**: fabric binding, post-state root, effect/chirality summary;
- **R**: parent instance, recursive depth, transform lineage;
- **P**: source provenance plus transformation closure receipt.

Section 03 does not create BRANE's request-relative realization coordinate `Z`.
