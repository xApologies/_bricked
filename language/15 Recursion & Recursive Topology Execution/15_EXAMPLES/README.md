# Section 15 examples

1. Direct well-founded countdown recursion.
2. Branching Fibonacci recursion with two decreasing recursive edges.
3. Multi-parameter recursion with an accumulator while only `n` is the proof metric.
4. Explicit finite-fuel recursion.
5. Visit-history recursion with repeated-key rejection semantics.
6. A recursive function calling another recursive function without creating a mutual recursion cycle.

Topology-graph and persistent-recursion examples are emitted in `16_REFERENCE_RUNS` because they exercise the runtime APIs rather than the v0.4 source subset.
