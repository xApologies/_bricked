# Failure model

Canonical Section 15 failure classes include:

- `RECURSION_UNGUARDED`
- `RECURSION_NOT_DECREASING`
- `RECURSION_DEPTH_EXCEEDED`
- `RECURSION_FUEL_EXHAUSTED`
- `RECURSION_VISIT_REPEAT`
- `RECURSION_MUTUAL_UNSUPPORTED`
- `RECURSION_RETURN_UNCLOSED`
- `RECURSION_ARITY`
- `RECURSION_TYPE`
- `RECURSION_STEP_BUDGET`
- `RECURSION_CONTINUATION_INVALID`
- `RECURSION_LINEAR_RESOURCE_CAPTURE`
- `TOPOLOGY_CYCLE`
