# Design invariants

1. **Effectful relative order is invariant** unless a future proof explicitly authorizes a transformation.
2. **Quantum linear resources are never copied.**
3. **Measurement is a hard barrier.**
4. **QFT/GR sector bridge order is invariant.**
5. **Portal and Rainbow Road open/append/close sequences are invariant.**
6. **Provenance-producing operations are not eliminated.**
7. **Exported values remain reachable and type-compatible.**
8. **Optimized GIR must pass Section 09 static checking again.**
9. **Generated GVM must pass Section 08 verification.**
10. **Reference execution equivalence is checked with fresh backends.**
