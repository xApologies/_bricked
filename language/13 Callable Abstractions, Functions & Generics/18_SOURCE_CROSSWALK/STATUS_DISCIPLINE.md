# Status discipline

`IMPLEMENTED` — executable in the Python reference toolchain and covered by tests.

`LANGUAGE CONTRACT` — normative Section 13 rule such as public callable visibility, generic bound checking, effect containment, recursion rejection, or monomorphization.

`REFERENCE ABI` — concrete serialization/naming choice that may change without changing source semantics, such as `__cN_*` internal names.

`DEFERRED` — explicitly not implemented in v0.1, including recursion, dynamic dispatch, captured closures, multiple returns, and native typed GVM stack frames.

`SOURCE LINEAGE` — inherited material preserved as provenance; not automatically rewritten as Section 13 semantics.
