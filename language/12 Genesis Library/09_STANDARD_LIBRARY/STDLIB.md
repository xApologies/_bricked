# Genesis standard library v0.1

Section 12 establishes these initial packages:

- `genesis.std.core` — contract root.
- `genesis.std.fabric` — executable reference chirality-fabric mount module.
- `genesis.std.atomic` — executable Hydrogen/Oxygen/HSV-1/blank Geometric fixture modules, dependent on `genesis.std.fabric`.
- `genesis.std.portal` — Portal/Corridor contract.
- `genesis.std.road` — Rainbow Road contract.
- `genesis.std.bridge` — QFT/GR bridge/transduction contract.
- `genesis.std.quantum` — quantum-information effect contract.
- `genesis.std.provenance` — history/provenance/closure contract.
- `genesis.std.brane` — BRANE lift/projection contract.
- `genesis.std` — meta-package over the standard package set.

Contract packages are intentionally contract-only at v0.1. Genesis does not yet have parameterized functions or generic callable abstractions, so Section 12 does not fake them with hidden Python semantics.
