# Transport-Holonomy Witness

Section 05 computes a deterministic Road transport signature over:

```text
ordered Portal IDs
ordered Corridor edge IDs
ordered color trajectory
chirality class
sector
source/final logical identity roots
```

This witness makes path/history dependence explicit and supports audit/replay comparisons.

It is deliberately named an **implementation transport-holonomy witness**. It does not promote the hash into the mathematical holonomy object of *Holonomy & Chirality* or into a physical observable.
