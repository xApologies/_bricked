# Failure Model

Representative failures:

```text
SYSTEM_CAPABILITY_MISSING
SYSTEM_ENDPOINT_UNKNOWN
SYSTEM_ENDPOINT_MODE
SYSTEM_PATH_ESCAPE
SYSTEM_REGISTER_UNDEFINED
SYSTEM_REGISTER_REDEFINED
SYSTEM_PROGRAM_UNCLOSED
SYSTEM_AFTER_CLOSE
CAS_OBJECT_MISSING
CAS_INTEGRITY_FAILURE
BRANE_PORT_INVALID
BRANE_PORT_NOT_MOUNTED
BRANE_CAPABILITY_UNAVAILABLE
BRANE_Z_CALLER_OWNED
BLACKGLASS_DIRECT_WRITE_FORBIDDEN
BLACKGLASS_PROPOSAL_UNKNOWN
BLACKGLASS_ADMISSION_AUTHORITY
DEVICE_CAPABILITY_UNAVAILABLE
SYSTEM_BYTECODE_TAMPER
```

A rejected operation must not be represented as a successful partial mutation. If a host side effect occurred before a later stage failed, the receipt must expose that committed boundary rather than pretending rollback happened.
