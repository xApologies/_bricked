# Trust Boundaries

Boundary 1: raw source vs derived interpretation.
Boundary 2: shared Base vs Hangar writable state.
Boundary 3: Hangar vs body branch.
Boundary 4: peer body vs peer body.
Boundary 5: model output vs authoritative commit.
Boundary 6: high-level cognition vs physical motor control.
Boundary 7: network transport vs durable state.

Crossing a trust boundary requires a typed receipt or explicit policy decision.
