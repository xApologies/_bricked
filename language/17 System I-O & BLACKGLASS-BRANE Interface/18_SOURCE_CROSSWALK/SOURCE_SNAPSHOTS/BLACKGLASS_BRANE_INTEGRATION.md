# BRANE Integration

BLACKGLASS contains/hosts BRANE services; BLACKGLASS is not reduced to BRANE.

Preserved source structure:

```text
B^6 = I x D x X x R x P x Z
M^5 = I x D x X x R x P
```

Operationally:
- Hangar identity state supplies `I` scope;
- graph supplies dependency `D`;
- admissibility/chirality machinery supplies `X`;
- recursive/recovery context supplies `R`;
- provenance service supplies `P`;
- request/event runtime supplies `Z` realization.

The reference BLACKGLASS core does not claim to implement this mathematics fully. It reserves fields and contracts so BRANE can be mounted without redesigning persistence/synchronization.
