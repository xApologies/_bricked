# System I/O Constitution

Genesis system I/O is a boundary algebra, not a thin alias over POSIX/Win32 calls.

Canonical planes:

```text
SOURCE      immutable evidence/canonical input
DERIVED     mutable derived execution artifacts
AUDIT       append-only operational receipts/events
CAS         immutable content-addressed artifacts
BRANE_PORT  validated five-dimensional module boundary
BLACKGLASS  durable host/persistence services
DEVICE      capability-typed physical/peripheral intent
```

Ordinary code cannot write SOURCE or canonical BRANE module state. A durable BLACKGLASS state change is a proposal followed by an authority-bearing admission step. The reference implementation makes this split visible even though both are simulated locally.
