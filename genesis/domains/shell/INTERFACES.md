# Shell interfaces

Adjacent domains: nexus, sea.

Sea mediates external interaction into Shell. Shell constructs commands and requests Nexus mediation; it cannot silently mutate State directly. Outward observation reverses that adjacent path.

Every future interface contract must specify direction, admissibility, Chirality constraints, Resolution, Bandwidth, authority, failure behavior and provenance. The implementation of these contracts is OPEN.
