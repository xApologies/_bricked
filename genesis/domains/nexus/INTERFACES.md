# Nexus interfaces

Adjacent domains: state, shell.

Shell sends command/relationship requests to Nexus; Nexus realizes admitted reads/writes against State and returns witnessed readout to Shell. No Nexus/Sea shortcut is introduced.

Every future interface contract must specify direction, admissibility, Chirality constraints, Resolution, Bandwidth, authority, failure behavior and provenance. The implementation of these contracts is OPEN.
