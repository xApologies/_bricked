# Sea interfaces

Adjacent domains: shell.

Sea couples to Shell, not directly to Nexus or State. The inter-fiber design target requires admitted Rainbow Road traversal; it does not establish a bypass or completed connection theorem.

Every future interface contract must specify direction, admissibility, Chirality constraints, Resolution, Bandwidth, authority, failure behavior and provenance. The implementation of these contracts is OPEN.
