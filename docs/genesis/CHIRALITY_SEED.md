# Chirality Seed

Status: WORKING CANON; color and propagation mathematics remain OPEN.

Each of the six cube faces is a Chirality Seed. Each Seed preserves four vertex
occupancies, face adjacency, two diagonal occupancy relationships, orientation,
and local Chirality/color state. A Seed is not reducible to occupied-vertex count.

The six Seeds are coupled by shared vertices. Each cube vertex belongs to three
faces, so changing one vertex changes the local configuration of the three
incident Seeds. Shared-vertex incidence is a native local coupling relationship.

The cube is the [Chirality Byte](CHIRALITY_BYTE.md). Shared-vertex incidence describes local geometric coupling; it does not supply the full Chirality propagation law. The Seed-to-color map and that propagation law remain OPEN. See [color organization](CHIRALITY_COLOR_ORGANIZATION.md).
