# Chirality Color Organization

Status: WORKING CANON; exact color mathematics remains OPEN.

`vertex occupancy -> Seed geometry -> face color -> Byte color`

Each Seed resolves under the authoritative Chirality color rule. Six face colors
compose to Byte-level color. Do NOT assume arithmetic averaging.

Color is native Chirality/energy-density organizational readout, not decorative UI.
Resolution may expose Byte color, face colors, Seed geometry/diagonals, and all
eight occupancies without changing Byte identity.

**Resolution reveals organization; it does not manufacture it.**

This hierarchy states an organizational dependency, not an implemented composition rule. The exact Chirality color algebra, Seed-to-color map, six-face-to-Byte color composition and full propagation law remain explicitly OPEN. No arithmetic average, interpolation, numeric color mapping or propagation formula is inferred. See [Seed](CHIRALITY_SEED.md) and [Byte](CHIRALITY_BYTE.md).
