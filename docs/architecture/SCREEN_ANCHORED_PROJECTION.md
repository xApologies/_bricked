# Screen-Anchored Projection
Status: WORKING CANON.

The display is an observation/interaction surface for a persistent higher-dimensional Genesis object.

Authoritative state -> dimensional observation -> observable 3D manifold -> camera -> 2D display.

The Genesis anchor remains a persistent reference while projected geometry changes.

Player operations:
- MOVE: position within current observable manifold.
- TRAVERSE: change dimensional observation/state.
- RESOLVE: change informational Resolution, not merely camera zoom.

The 7/8 Shell may remain sphere-like in its current 3D projection while interaction operates on higher-dimensional Shell state. Traced command/Corridor paths persist as authoritative geometry even when their visible projection changes.

VFX expose/decorate state; they do not substitute for state.
