# Layer Zero — Information Path

Status: WORKING CANON; interface mathematics remains OPEN.

## Governing statement

**The Shell writes to the Sphere through the Hypercube, and we interact with the Shell through the Sea.**

This defines the first complete information topology of the four-object Genesis computer.

## Inward path — interaction / command / write

`Observer or external interaction -> Genesis Sea -> Shell -> Hypercube -> Sphere`

Roles:

- **Sea -> Shell:** interaction coupling/mediation.
- **Shell -> H6:** command/address request.
- **H6 -> R5:** read/write realization against authoritative native state.

The Shell does not directly write R5. The Sea does not directly write R5.

## Outward path — read / observation

`Sphere -> Hypercube -> Shell -> Genesis Sea -> observer/external representation`

Roles:

- **R5 -> H6:** authoritative state becomes addressable/readable.
- **H6 -> Shell:** state readout becomes Shell/interface state.
- **Shell -> Sea:** Shell state couples into the outer computer container.
- Downstream Horizon/Hypervisor transduction may expose permitted state to an ordinary host/rendering platform.

## No-direct-jump invariant

Layer Zero operations follow the four-object topology:

`S9:11 <-> Sigma7:8 <-> H6 <-> R5`

No adjacent mediation layer may be silently bypassed in the canonical model unless a future explicit architecture decision defines such a path.

## Three interface contracts to formalize next

1. `I_Sea/Shell` — what may cross between the Genesis Sea and Shell.
2. `I_Shell/H6` — how Shell command geometry becomes a read/write/address request.
3. `I_H6/R5` — how H6 reads or transforms authoritative R5 state.

Each future interface contract should specify direction, admissibility, Chirality constraints, Resolution, Bandwidth, authority, failure behavior, and provenance.

## Mathematical skeleton

Working containment/embedding notation:

`R5 -> H6 -> Sigma7:8 -> S9:11`

The arrows currently denote accepted containment/interface relationships, not yet-completed embedding proofs.

Exact embedding maps, Shell coupling, Sea phase coupling, and the Sea–Shell interaction functional remain OPEN.
