# Genesis Horizon
Status: WORKING CANON.

The Genesis Horizon is the boundary where Genesis-native rules meet ordinary host computation.

Inside: Genesis-native state, Chirality, Resolution, Bandwidth, Guardian, Sea, Shell, recursive computation and applications.
Outside: Python host/hypervisor, binary representation, native adapters and renderers.

Outbound transduction:
Genesis state -> Horizon exposure -> admissible exposed state -> serialization -> bytes.

Inbound:
host bytes -> decode -> validate -> Horizon admission -> Genesis operation.

No internal state crosses directly and no external input directly mutates Genesis.

Project thesis: We are a transduction framework, full stop.
