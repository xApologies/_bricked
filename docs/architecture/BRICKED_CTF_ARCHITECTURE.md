# _bricked Role

_bricked remains both native capture-the-flag game and Genesis architecture proving
ground.

Design triad:
game mechanic <-> architecture property <-> security test.

Puzzle/test families may exercise Resolution, Bandwidth, Chirality/orientation,
DECS/History/provenance, Corridors, Portals, Road routing, Nexus mediation, State
recovery, replay/rollback, route degradation, scope escalation and multi-fiber Sea
navigation.

Virtual Boxing/Ghosting remain isolated authorized testing concepts.
CDN/DECS remains security research input, not completed cryptography.

Status: WORKING design direction; no runtime or completed cryptography is introduced.
