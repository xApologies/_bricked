# 0004 — Layer Zero four-object Genesis computer

Date: 2026-09-22
Status: working architecture decision.

Accepted:
- Eleven modeled dimensions are organized into four geometric objects, not eleven individually nested software layers.
- D5 forms the five-dimensional Sphere/native state object R5.
- D6 forms the Hypercube/read-write object H6 containing/addressing R5.
- D7/D8 jointly form one coupled/superposed command Shell.
- D9/D10/D11 jointly form one coupled Genesis Sea/container object.
- The Genesis Sea is part of the computer: it is the outer containing organization, not an environment external to the machine.
- The superionic-ice analogy applies to the Sea's proposed persistent-framework/mobile-phase organization only; it is not a claim of molecular chemistry.
- The accepted information path is Sea <-> Shell <-> H6 <-> R5.
- The Shell writes to/reads the Sphere through H6.
- External/user interaction with the Shell is mediated through the Sea.
- Direct jumps between nonadjacent objects are not part of Layer Zero unless explicitly introduced later.
- Exact D7/D8 and D9/D10/D11 coupling mathematics remains OPEN.
- Do not assign separate software meanings to D9, D10, D11 merely because they are separately numbered dimensions.

This decision refines the earlier 11D architecture without replacing the Genesis Horizon/Hypervisor transduction boundary.
