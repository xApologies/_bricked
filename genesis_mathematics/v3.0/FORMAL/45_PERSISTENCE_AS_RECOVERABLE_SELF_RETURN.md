# 45 — PERSISTENCE AS RECOVERABLE SELF-RETURN

## Definition 45.1 — Persistence

A state \(x\) is persistent under admitted change \(r:x\to y\) when there exists an admissible recovery history

\[
h:y\to x'
\]

with

\[
x'\sim_I x
\]

and required provenance intact.

Thus:

\[
\boxed{
\text{Persistence is recoverability of identity under admissible change.}
}
\]

Persistence is not coordinate immobility.

## Definition 45.2 — Recovery saturation

A bounded domain is recovery-saturated when every admitted internal transformation that is required by the domain's closure contract is recoverable to the relevant identity class.

This is a Genesis closure concept independent of any natural-law stage labels.
